# Contributing

This repository is the source for a personal site. Unsolicited code and content contributions are
not currently accepted.

Opening a pull request does not create a commitment to review, merge, publish, attribute, or
license the submitted material. If repository issues are enabled, use an issue for ordinary
corrections or non-sensitive site feedback. Report suspected vulnerabilities privately as
described in `SECURITY.md`.

The contribution policy may change if this repository becomes an open contributor community. A
Code of Conduct would be added at that time.
